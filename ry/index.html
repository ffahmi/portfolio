Role Product Designer
Timeline 4 Weeks (2023)
Platform Web Application
Tools Figma

Project Overview

Moota.co is an Indonesian fintech platform designed to help businesses and individuals track and manage bank transactions across multiple accounts. The goal of this redesign was to modernize the interface, improve data visualization for financial health, and streamline the user flow for connecting new bank accounts. The existing platform suffered from high churn during the onboarding process and a cluttered dashboard that made quick analysis difficult.

The Problem

Through user interviews and heatmap analysis, we identified several critical friction points:

  • close Complex Onboarding: Users felt overwhelmed by the 7-step process to link their first bank account.
  • close Data Overload: The dashboard displayed raw tables without visual summaries, making it hard to spot trends.
  • close Inconsistent UI: Legacy design elements clashed with newer features, creating a disjointed trust experience.

The Solution

We adopted a "Focus and Clarity" design philosophy. We simplified the onboarding into a 3-step wizard with clear progress indicators. For the dashboard, we introduced modular widgets allowing users to customize their view—prioritizing charts and aggregate totals over raw data rows. The visual language was updated to a deep, trustworthy blue palette with high-contrast accents for critical financial alerts, ensuring accessibility and a modern aesthetic.

Key Outcomes

Conversion Rate +24%
Time on Task -40%
User Satisfaction 4.8/5
